# Assessment practice

## How we work

1. Choose the current exercise and solve it without AI, as you will in the assessment.
2. You may use Google or Stack Overflow only for a specific syntax question.
3. Run your own `print()` statements and test edge cases.
4. Tell me when you finish. We will review the reasoning, result, and tests before moving on.
5. Each file only provides the problem and examples. Write the `def`, function name,
   parameters, and implementation yourself.

Do not search for a solution or paste the exercise statement into a search engine.

## Roadmap

### Stage 1 — tools you have already seen

- [ ] `01_count_word_occurrences.py` — three dictionary-counting exercises.
- [ ] `02_first_unique_character.py` — three “first unique item” exercises.
- [ ] `03_two_sum_clean.py` — three complement / Two Sum exercises.

### Stage 2 — learn `set`

- [ ] `04_sets_detect_duplicates.py` — three exercises using `set()` to detect
  repeated values and preserve unique values in order.

### Stage 3 — dictionaries as counters

- Mini topic: `dict.get(key, default)`.
- Exercise: compare character/word frequencies.

### Stage 4 — stack

- Mini topic: list as a stack with `append()` and `pop()`.
- Exercise: balanced parentheses.

### Stage 5 — sort and search

- Review: `.sort()` and `sorted()`.
- Exercise: sort without changing the original list.
- Mini topic: two pointers.
- Exercise: find pairs in a sorted list.

### Stage 6 — final practice

- State simulation: loops, conditionals, and dictionaries.
- Timed mini mock assessment without AI, using new exercises.

## Edge cases we always test

- Empty input.
- One element.
- Duplicates.
- Negative values, when working with numbers.
- Boundary indexes.
- No valid result.
